
Inheritance
Inheritance is a feature in object-oriented programming where one class or interface can take the features of another. 
It allows us to reuse existing code instead of writing it from scratch. The new class can also add its own features or modify the behavior it inherited.

Key Points:
• Inheritance can happen between class-to-class or interface-to- interface.
  It helps avoid code duplication by reusing existing functionality.
• The derived class can extend or change the inherited behavior
